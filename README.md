# SWAT Strike releases

Android builds of SWAT Strike, a 2D side-view 3v3 team shooter.

**Install:** open [the latest release](https://github.com/Frenzy911/swat-strike-releases/releases/latest) on your phone, download the `.apk` and open it (allow installs from your browser if Android asks). Installing over an older version keeps your coins, skins and settings.

**Playing together:** every phone in a match needs the same build.

`version.json` is what the game reads on start to tell players a new version is out. Keep `version` in step with the newest release.
